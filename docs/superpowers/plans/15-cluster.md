# Plan 15 — `RedisCluster` (sync + async) façade

> **For agentic workers:** REQUIRED SUB-SKILL: Use [superpowers:subagent-driven-development](https://) (recommended) or [superpowers:executing-plans](https://) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the `RedisCluster` and `AsyncRedisCluster` Rust pyclasses — redis-py-shaped cluster façades that wrap `redis::cluster_async::ClusterConnection` via `RedisRsDriver::connect_cluster`. Every command shipped in plans 03–09 forwards to the driver; cross-slot multi-key commands fan out per-key over `tokio::join_all`; cluster-admin commands (`CLUSTER NODES`/`SLOTS`/`SHARDS`/etc.) ship as first-class methods. `pubsub()` returns a sharded `ClusterPubSub`; `pipeline()` is fan-out only (no transaction support across slots). Client-side caching is unsupported on cluster (redis-rs limitation) — passing `cache_max_size`/`cache_ttl_secs` raises a one-shot warning. MOVED/ASK retries are delegated to redis-rs `cluster_async`.

**Architecture:** Lift the cluster-connection wiring from `django-cachex/crates/django-cachex-redis-rs/src/connection.rs` (the `ClusterConnection` arm of `ValkeyConnInner`, `connect_cluster`, the `ConnConfig::Cluster` variant, the lazy blocking-conn path). The façade pyclasses live in `crates/redis-rs-py-driver/src/facade/cluster.rs` and follow the `RedisRsClient`/`asyncio.RedisRsClient` shape from plan 10/11: each command is generated by a `define_cluster_command!` macro that wraps the driver call, leaving behavior identical to the standard façade *except* for the multi-key fan-out helpers (`mget_fanout`, `mset_fanout`, `del_fanout`, `exists_fanout`, `unlink_fanout`) and the cluster-only kwargs (`startup_nodes`, `read_from_replicas`, `dynamic_startup_nodes`, `max_connections_per_node`). Sharded pub/sub and `KEYS *` are fan-out per-shard, hitting every master. `kwargs.rs` (added in plan 10) is extended with the cluster-specific accept-and-warn list.

**Tech Stack:** Rust 2024, PyO3 0.28, tokio (`rt-multi-thread`, `sync`, `time`), redis 1.x with `cluster` + `cluster-async` features (already enabled in `Cargo.toml`), `futures::future::join_all` (transitively pulled in by tokio's `join_all`-equivalent — we use `tokio::task::JoinSet` to avoid a new dep). On the Python side: pytest + pytest-asyncio + testcontainers + the upstream `redis-py` for parity assertions. Python 3.14 + 3.14t.

```python
# =========================================================================
# Cluster fixture — six-node cluster (3 masters + 3 replicas) via testcontainers.
# =========================================================================
#
# This is the trickiest infrastructure in the project. Strategy:
#   * Spin six standalone Valkey containers on a shared docker network.
#   * Run CLUSTER MEET to wire them together, ADDSLOTS to partition the
#     16384 slots across the 3 masters, then CLUSTER REPLICATE to attach
#     each replica.
#   * Wait until `CLUSTER INFO` reports `cluster_state:ok`.
#   * Yield a list of three master URLs (cluster mode opens its own
#     connections to the rest of the topology after MOVED).
#
# `bitnami/valkey-cluster` is an alternative — but it forces port-binding
# at fixed 7000–7005 which clashes under xdist. The hand-rolled version
# below uses ephemeral ports + the docker network for the inter-node
# CLUSTER MEET, then exposes each node's client port back to the host.

from __future__ import annotations

import socket
import subprocess
import time
from collections.abc import Iterator
from contextlib import closing

import pytest
import redis as upstream_redis
from filelock import FileLock
from testcontainers.core.container import DockerContainer
from testcontainers.core.network import Network
from testcontainers.core.waiting_utils import wait_for_logs


CLUSTER_NODE_COUNT = 6  # 3 masters + 3 replicas
SLOT_TOTAL = 16384


def _cluster_command(container: DockerContainer, *args: str) -> str:
    """Run valkey-cli inside a container and return the trimmed stdout."""
    cmd = ["valkey-cli", "-c", "-p", "6379", *args]
    rc, out = container.exec(cmd)
    if rc != 0:
        raise RuntimeError(f"valkey-cli {args} failed: {out!r}")
    return out.decode().strip() if isinstance(out, (bytes, bytearray)) else out.strip()


def _spawn_cluster() -> tuple[Network, list[DockerContainer], list[str]]:
    """Bring up a 3-master/3-replica cluster on a fresh docker network.

    Returns (network, containers, master_urls). All containers use the
    same network so CLUSTER MEET can reach peers by container name; the
    six exposed ports are mapped back to host so Python clients can
    connect from outside the network.
    """
    network = Network()
    network.create()

    containers: list[DockerContainer] = []
    for idx in range(CLUSTER_NODE_COUNT):
        name = f"valkey-cluster-node-{idx}"
        c = (
            DockerContainer(VALKEY_IMAGE)
            .with_network(network)
            .with_name(name)
            .with_exposed_ports(6379)
            .with_command(
                "valkey-server "
                "--cluster-enabled yes "
                "--cluster-node-timeout 5000 "
                "--appendonly yes "
                "--save \"\" "
                "--protected-mode no "
                "--port 6379"
            )
        )
        c.start()
        wait_for_logs(c, "Ready to accept connections", timeout=30)
        containers.append(c)

    # Step A: CLUSTER MEET — point node 0 at every other node so they all
    # hear about each other. Use the in-network address (container name +
    # internal port 6379), NOT the exposed host port.
    for idx in range(1, CLUSTER_NODE_COUNT):
        peer_name = f"valkey-cluster-node-{idx}"
        _cluster_command(containers[0], "CLUSTER", "MEET", peer_name, "6379")

    # Wait for full topology propagation.
    deadline = time.monotonic() + 15
    while time.monotonic() < deadline:
        info = _cluster_command(containers[0], "CLUSTER", "INFO")
        nodes = _cluster_command(containers[0], "CLUSTER", "NODES").splitlines()
        if "cluster_known_nodes:6" in info and len(nodes) == CLUSTER_NODE_COUNT:
            break
        time.sleep(0.5)
    else:
        raise RuntimeError("cluster topology did not propagate within 15s")

    # Step B: ADDSLOTS — partition 16384 slots across the 3 masters
    # (containers 0, 1, 2). Replicas are containers 3, 4, 5.
    masters = containers[:3]
    replicas = containers[3:]
    slots_per_master = SLOT_TOTAL // 3  # 5461 each, last one gets the +1
    cursor = 0
    for m_idx, master in enumerate(masters):
        end = cursor + slots_per_master + (1 if m_idx == len(masters) - 1 else 0)
        _cluster_command(master, "CLUSTER", "ADDSLOTSRANGE", str(cursor), str(end - 1))
        cursor = end

    # Step C: collect master node IDs and instruct each replica to follow
    # one of them. Order: replica i replicates master i.
    master_ids: list[str] = []
    for master in masters:
        # `CLUSTER MYID` returns the 40-char hex node id of the calling node.
        master_ids.append(_cluster_command(master, "CLUSTER", "MYID"))

    for r_idx, replica in enumerate(replicas):
        master_id = master_ids[r_idx]
        # CLUSTER REPLICATE requires the replica to know the master, so
        # poll briefly until CLUSTER NODES on the replica lists it.
        deadline = time.monotonic() + 10
        while time.monotonic() < deadline:
            nodes = _cluster_command(replica, "CLUSTER", "NODES")
            if master_id in nodes:
                break
            time.sleep(0.3)
        else:
            raise RuntimeError(
                f"replica {r_idx} could not see master {master_id} within 10s"
            )
        _cluster_command(replica, "CLUSTER", "REPLICATE", master_id)

    # Step D: wait until CLUSTER INFO says cluster_state:ok.
    deadline = time.monotonic() + 30
    while time.monotonic() < deadline:
        info = _cluster_command(containers[0], "CLUSTER", "INFO")
        if "cluster_state:ok" in info:
            break
        time.sleep(0.5)
    else:
        raise RuntimeError("cluster_state never reached ok")

    # Step E: collect host-mapped URLs for the three masters.
    master_urls: list[str] = []
    for master in masters:
        host = master.get_container_host_ip()
        port = master.get_exposed_port(6379)
        master_urls.append(f"redis://{host}:{port}")

    return network, containers, master_urls

/// Connect to a Valkey/Redis cluster across `urls` startup nodes.
///
/// Client-side caching is **not** supported in cluster mode (redis-rs
/// cluster_async has no CacheConfig hook); pass-through cache opts are
/// silently ignored at this layer — the façade emits a one-shot warning
/// when the user actually passes `cache_max_size` / `cache_ttl_secs`.
pub async fn connect_cluster(
    urls: Vec<String>,
    tls_opts: Option<TlsOpts>,
) -> Result<ValkeyConn, String> {
    if urls.is_empty() {
        return Err("connect_cluster: at least one startup URL required".into());
    }
    let url_refs: Vec<&str> = urls.iter().map(|s| s.as_str()).collect();
    let client = match &tls_opts {
        Some(opts) => ClusterClient::builder(url_refs)
            .certs(opts.to_tls_certs())
            .build(),
        None => ClusterClient::new(url_refs),
    }
    .map_err(|e| format!("Invalid cluster URLs: {e}"))?;
    let conn = client
        .get_async_connection()
        .await
        .map_err(|e| format!("Cluster connection failed: {e}"))?;
    Ok(ValkeyConn {
        regular: ValkeyConnInner::Cluster(conn),
        blocking: Arc::new(OnceCell::new()),
        config: ConnConfig::Cluster {
            urls: Arc::from(urls),
            tls_opts,
        },
    })
}
```

/// Helper: build the startup-URL list from any combination of
/// (host/port, startup_nodes, url). Errors if all three are absent.
fn resolve_startup_urls(
    py: Python<'_>,
    host: Option<&str>,
    port: u16,
    startup_nodes: Option<&Bound<'_, PyList>>,
    url: Option<&str>,
) -> PyResult<Vec<String>> {
    if let Some(u) = url {
        return Ok(vec![u.to_string()]);
    }
    if let Some(nodes) = startup_nodes {
        let mut out = Vec::with_capacity(nodes.len());
        for item in nodes.iter() {
            let cn: PyRef<ClusterNode> = item.extract()?;
            out.push(format!("redis://{}:{}", cn.host, cn.port));
        }
        if !out.is_empty() {
            return Ok(out);
        }
    }
    if let Some(h) = host {
        return Ok(vec![format!("redis://{h}:{port}")]);
    }
    let _ = py;
    Err(PyErr::new::<DataError, _>(
        "RedisCluster requires one of: host=, url=, or startup_nodes=[ClusterNode(...)]",
    ))
}

/// Insert user[:password] into a URL between scheme:// and host:port.
fn inject_userinfo(url: &str, user: Option<&str>, pw: Option<&str>) -> String {
    let (scheme, rest) = match url.split_once("://") {
        Some(x) => x,
        None => return url.to_string(),
    };
    let userinfo = match (user, pw) {
        (Some(u), Some(p)) => format!("{u}:{p}@"),
        (Some(u), None) => format!("{u}@"),
        (None, Some(p)) => format!(":{p}@"),
        (None, None) => String::new(),
    };
    format!("{scheme}://{userinfo}{rest}")
}

    m.add_class::<RedisCluster>()?;
    parent.add_submodule(&m)?;
    let _ = PyTuple::empty(py); // silence unused import in skeleton
    Ok(())
}

// Accept-and-warn for redis-py kwargs the façade does not implement.
//
// One warning per (kwarg, process) — the OnceLock-of-HashSet pattern.

use std::collections::HashSet;
use std::sync::Mutex;
use std::sync::OnceLock;

use pyo3::prelude::*;
use pyo3::types::PyDict;

static WARNED: OnceLock<Mutex<HashSet<String>>> = OnceLock::new();

fn warned_set() -> &'static Mutex<HashSet<String>> {
    WARNED.get_or_init(|| Mutex::new(HashSet::new()))
}

pub fn warn_unknown_kwargs(
    py: Python<'_>,
    kwargs: &Bound<'_, PyDict>,
    accept: &[&str],
) -> PyResult<()> {
    let warnings = py.import("warnings")?;
    let warning_cls = py.get_type::<pyo3::exceptions::PyUserWarning>();
    for (k, _v) in kwargs.iter() {
        let name: String = k.extract()?;
        if accept.contains(&name.as_str()) {
            continue;
        }
        let mut set = warned_set().lock().unwrap();
        if set.insert(name.clone()) {
            let msg = format!(
                "redis-rs-py: kwarg {name!r} is accepted for redis-py compatibility but \
                 not yet implemented; the value is ignored. (Warned once per process.)"
            );
            warnings.call_method1("warn", (msg, &warning_cls))?;
        }
    }
    Ok(())
}

/// Generates a sync façade method that forwards to the wrapped driver.
///
/// `$name` — Python-visible method name.
/// `$ret`  — Python return-type hint for stub generators (unused at runtime).
///
/// Variadic args: positional args go into the call_method tuple in order;
/// optional kwargs go into a PyDict if present.
#[macro_export]
macro_rules! define_cluster_command {
    // Variant A: 1-arg → 1-result, simple forward.
    ($name:ident, $($arg:ident : $ty:ty),* $(,)?) => {
        fn $name(
            &self,
            py: Python<'_>,
            $($arg: $ty,)*
        ) -> PyResult<Py<PyAny>> {
            let driver = self.driver.bind(py);
            let args = ($($arg,)*);
            let result = driver.call_method1(stringify!($name), args)?;
            Ok(result.unbind())
        }
    };
}

    fn mget_fanout(&self, py: Python<'_>, keys: Vec<String>) -> PyResult<Py<PyAny>> {

            return Ok(pyo3::types::PyList::empty(py).into_any().unbind());

        let conn = self.connection.clone();

                None => py.None(),

// =========================================================================
// Cross-slot fan-out helpers (used by RedisCluster only — RedisRsClient
// just forwards to the standard MGET/MSET/DEL bodies).
// =========================================================================

use crate::connection::ValkeyConnInner;

/// Group `keys` by Redis cluster slot using the canonical CRC16 algorithm,
/// preserving the input order index so we can re-shuffle results back.
fn group_by_slot(keys: &[String]) -> std::collections::HashMap<u16, Vec<(usize, String)>> {
    let mut map: std::collections::HashMap<u16, Vec<(usize, String)>> =
        std::collections::HashMap::new();
    for (idx, k) in keys.iter().enumerate() {
        let slot = redis::cluster_routing::get_slot(k.as_bytes());
        map.entry(slot).or_default().push((idx, k.clone()));
    }
    map
}

async fn fanout_mget(
    conn: crate::connection::ValkeyConn,
    keys: Vec<String>,
) -> redis::RedisResult<Vec<Option<Vec<u8>>>> {
    let groups = group_by_slot(&keys);
    let mut out: Vec<Option<Vec<u8>>> = vec![None; keys.len()];
    let mut set: tokio::task::JoinSet<
        redis::RedisResult<(Vec<usize>, Vec<Option<Vec<u8>>>)>,
    > = tokio::task::JoinSet::new();
    for (_, entries) in groups {
        let mut conn = conn.clone();
        set.spawn(async move {
            let (indices, slot_keys): (Vec<_>, Vec<_>) = entries.into_iter().unzip();
            let mut cmd = redis::cmd("MGET");
            for k in &slot_keys {
                cmd.arg(k);
            }
            let result: Vec<Option<Vec<u8>>> = $crate::dispatch_cmd!(&mut *conn, cmd)?;
            Ok((indices, result))
        });
    }
    while let Some(joined) = set.join_next().await {
        let (indices, values) = joined.map_err(|e| {
            redis::RedisError::from((redis::ErrorKind::Io, "fanout join", e.to_string()))
        })??;
        for (i, v) in indices.into_iter().zip(values.into_iter()) {
            out[i] = v;
        }
    }
    Ok(out)
}

async fn fanout_mset(
    conn: crate::connection::ValkeyConn,
    pairs: Vec<(String, Vec<u8>)>,
) -> redis::RedisResult<()> {
    let mut groups: std::collections::HashMap<u16, Vec<(String, Vec<u8>)>> =
        std::collections::HashMap::new();
    for (k, v) in pairs {
        let slot = redis::cluster_routing::get_slot(k.as_bytes());
        groups.entry(slot).or_default().push((k, v));
    }
    let mut set: tokio::task::JoinSet<redis::RedisResult<()>> = tokio::task::JoinSet::new();
    for (_, group) in groups {
        let mut conn = conn.clone();
        set.spawn(async move {
            let mut cmd = redis::cmd("MSET");
            for (k, v) in &group {
                cmd.arg(k).arg(v.as_slice());
            }
            $crate::dispatch_cmd!(&mut *conn, cmd)
        });
    }
    while let Some(joined) = set.join_next().await {
        joined.map_err(|e| {
            redis::RedisError::from((redis::ErrorKind::Io, "fanout join", e.to_string()))
        })??;
    }
    Ok(())
}

async fn fanout_del(
    conn: crate::connection::ValkeyConn,
    keys: Vec<String>,
    unlink: bool,
) -> redis::RedisResult<i64> {
    let groups = group_by_slot(&keys);
    let cmd_name = if unlink { "UNLINK" } else { "DEL" };
    let mut set: tokio::task::JoinSet<redis::RedisResult<i64>> = tokio::task::JoinSet::new();
    for (_, entries) in groups {
        let mut conn = conn.clone();
        let cmd_name = cmd_name.to_string();
        set.spawn(async move {
            let mut cmd = redis::cmd(&cmd_name);
            for (_, k) in &entries {
                cmd.arg(k);
            }
            $crate::dispatch_cmd!(&mut *conn, cmd)
        });
    }
    let mut total = 0i64;
    while let Some(joined) = set.join_next().await {
        let n = joined.map_err(|e| {
            redis::RedisError::from((redis::ErrorKind::Io, "fanout join", e.to_string()))
        })??;
        total += n;
    }
    Ok(total)
}

async fn fanout_exists(
    conn: crate::connection::ValkeyConn,
    keys: Vec<String>,
) -> redis::RedisResult<i64> {
    let groups = group_by_slot(&keys);
    let mut set: tokio::task::JoinSet<redis::RedisResult<i64>> = tokio::task::JoinSet::new();
    for (_, entries) in groups {
        let mut conn = conn.clone();
        set.spawn(async move {
            let mut cmd = redis::cmd("EXISTS");
            for (_, k) in &entries {
                cmd.arg(k);

        total += joined.map_err(|e| {
            redis::RedisError::from((redis::ErrorKind::Io, "fanout join", e.to_string()))
        })??;
    }

}

fn cluster_slot(key: &[u8]) -> u16 {
    // Honour {hash-tag} braces if present.
    let target: &[u8] = match (key.iter().position(|&b| b == b'{'), key.iter().position(|&b| b == b'}')) {
        (Some(start), Some(end)) if end > start + 1 => &key[start + 1..end],
        _ => key,
    };
    let mut crc: u16 = 0;
    for &b in target {
        crc = ((crc << 8) ^ CRC16_XMODEM[((crc >> 8) ^ b as u16) as usize & 0xff]) & 0xffff;
    }
    crc & 0x3fff
}
